Penyimpanan Gambar (GitHub)

Belum diatur

Gambar tutorial disimpan di folder images/ repo , lalu tayang setelah deploy otomatis (±2–3 menit). Token GitHub disimpan sekali di Tool Hub, jadi admin tidak perlu memegang token.

Cara membuat token
  1. Login GitHub (akun pemilik repo), buka Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: tutorial-admin. Expiration: 90 hari (atau sesuai kebijakan).
  3. Repository access: Only select repositories → pilih repo proyek ini saja.
  4. Permissions → Repository permissions → Contents: Read and write. Yang lain biarkan.
  5. Generate, salin token, tempel di kotak di atas, klik Simpan & Tes.
