# Logo resmi

Hanya logo di folder ini yang boleh dipakai. Ukurannya sudah dikecilkan dari file asli; latar transparan.

| File | Isi | Dipakai untuk |
|---|---|---|
| `ikisi-color.png` | iKISI "Elevate Your Investing", teks hijau | Logo iKISI di latar terang: report PDF, PPT, materi lain |
| `ikisi-white.png` | iKISI "Elevate Your Investing", teks putih | Logo iKISI di latar gelap |
| `kisi-color.png` | trueFriend Korea Investment & Sekuritas Indonesia, berwarna | Logo perusahaan di latar terang |
| `kisi-white.png` | Logo perusahaan, putih | Logo perusahaan di latar gelap |
| `truefriend-color.png` | Wordmark trueFriend, berwarna | Ruang sempit di latar terang |
| `truefriend-white.png` | Wordmark trueFriend, putih (garis tepi) | Ruang sempit di latar gelap |
| `truefriend-mark.png` | Simbol 友 saja (persegi) | Ikon, favicon, avatar |

Kalau butuh logo iKISI, selalu pakai `ikisi-color.png` / `ikisi-white.png` (versi "Elevate Your Investing"), jangan versi lain.

Tool menyajikan logo dari folder `assets/brand` miliknya sendiri (mis. `apps/market-news/assets/brand/logo-color.png`, salinan logo perusahaan). Saat sebuah tool butuh logo baru, salin dari folder ini.
Karena repo publik, file ini juga bisa dipakai lewat URL lintas situs (CORS), mis. untuk `brand.logo` / `app.logo` di profile.json:
`https://cdn.jsdelivr.net/gh/frankykho/PDD-Tool-Hub@main/brand/ikisi-color.png`
