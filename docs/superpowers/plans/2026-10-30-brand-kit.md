# Brand Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new Tool Hub tool, Brand Kit. Branches fill locked templates (branch name, date, place, up to 6 speakers, optional QR) and download digital PNGs or print PDFs. The tool also lists official files from a Google Drive folder and holds the official disclaimer texts. Those texts are pushed to Copy Studio and Edukasi Studio.

**Architecture:**
- A new Cloudflare Worker `apps/brand-kit`:
  - worker name and deploy id `brand`,
  - D1 `brand-db`,
  - KV `BRAND_KV` for template background images,
  - static `assets/` (company logos, `render.js`).
- Login uses the same HUBSSO pattern as Event & Lead.
- All image work happens in the browser on a canvas:
  - pure layout maths in `assets/render.js` (ES module, also imported by the Node tests),
  - drawing code in the same file.
- Service bindings go one way only: Brand Kit → `EVENT`, `COPY`, `EDUKASI`.
  - Disclaimers are **pushed** to Copy Studio and Edukasi Studio, which keep their own copy.
  - Nothing calls Brand Kit except the hub's user sync, so there are no deploy cycles.
- Drive file listing uses the Drive API v3 with secret `DRIVE_API_KEY`, cached 10 minutes in KV.

**Tech Stack:**
- Cloudflare Workers + D1 + KV (free plan). Plain JS, no build step, no npm dependencies.
- In the browser (cdnjs, fixed versions):
  - `qrcode-generator@1.4.4`: `https://cdnjs.cloudflare.com/ajax/libs/qrcode-generator/1.4.4/qrcode.min.js`
  - `jspdf@2.5.1`: `https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js`
  - `jszip@3.10.1`: `https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js`
  - Google Fonts: Montserrat, Poppins, Inter, Open Sans (400/600/700/800).
- Tests: Node 22 + `node:sqlite`, following the `apps/event-lead/test.mjs` pattern.

**Spec:** `docs/superpowers/specs/2026-10-30-brand-kit-design.md`

## Global Constraints

- **UI language:** All user-facing text is Indonesian. Every new string gets an English entry in the tool's `i18n.js`, and `node scripts/i18n-check.mjs` must pass.
- **Comments:** short Indonesian comments, matching the repo.
- **Deploy:**
  - `wrangler.jsonc` name is `brand`, so the URL is `https://brand.<subdomain>.workers.dev`.
  - Deploy id `brand`, placed in `scripts/deploy.mjs` APPS **right after `event`**.
  - `hub` stays last.
- **Links to the tool:** built from `appUrl(env, "brand")`, never hard-coded.
- **No new cron:** all 5 free cron slots are used.
- **Who can do what:**
  - Every Brand Kit user may: use templates, download, copy disclaimers, add speakers.
  - Only hub admins (`me.adm`) may change templates, disclaimers, and the Drive folder.
  - A speaker may be edited or deleted by its creator, any Head (`roleIn(org, me.j).head`), or an admin.
- **Size presets:** pixel sizes include a 3 mm bleed on print sizes. Use these exact values:

| kind | label | px (w×h) | output | paper incl. bleed (mm) |
|---|---|---|---|---|
| `story` | Story | 1080×1920 | PNG | – |
| `feed45` | Feed 4:5 | 1080×1350 | PNG | – |
| `feed11` | Feed persegi | 1080×1080 | PNG | – |
| `a4` | A4 | 2551×3579 | PDF + PNG | 216×303 |
| `a3` | A3 | 3579×5031 | PDF + PNG | 303×426 |
| `xbanner` | X-banner 60×160 | 2386×6323 | PDF + PNG | 606×1606 |

- **Print files:** no crop marks, RGB. PDF page size = paper incl. bleed. The editor shows the trim line (3 mm in) and a safe line (6 mm in).
- **Canvas limit:** never create a canvas over **16,000,000 px**. Scale the whole drawing down to fit. In practice only A3 is affected; the PDF keeps its mm size.
- **Fonts:** only `["Montserrat", "Poppins", "Inter", "Open Sans"]`. Wait for `document.fonts.load` before drawing.
- **Speakers:** max 1–6 per size. Row rule: 1–3 → one row; 4 → 2+2; 5 → 3+2; 6 → 3+3.
- **Locked elements:** the tool always draws the company logo and the disclaimer. Branches cannot change or remove them.
  - Logo: `brand/kisi-color.png` on light backgrounds, `brand/kisi-white.png` on dark, horizontally centred.
  - `xbanner` always uses disclaimer `singkat`.
- **Disclaimer keys** (in order): `umum` Umum, `reksadana` Reksa Dana, `obligasi` Obligasi, `syariah` Syariah, `edukasi` Edukasi, `singkat` Singkat.
  - Seeds:
    - `edukasi` = Edukasi Studio's current text, plus the profile licence line if present.
    - `singkat` = `PT Korea Investment And Sekuritas Indonesia berizin dan diawasi oleh OJK.`
    - The others start empty.
  - A size whose disclaimer version is empty cannot go live.
- **Empty optional slots are not drawn.**
- **Commits:** messages in Indonesian, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not push; the user approves pushes.
- **Line endings:** `apps/tool-hub/worker.js` uses CRLF. Keep them (no `sed -i` on that file).
- **Secrets:** never read `.secrets.json`.

## Review Focus

1. **A long branch name or speaker name:** text shrinks down to `minSize`. If it still does not fit, the field is flagged and nothing is drawn outside the box. → Task 8 test `fitText`.
2. **More speakers than one size allows** (5 picked, X-banner max 3): that size draws the first 3, and the preview says so. → Task 8 test `speakersFor`.
3. **An Edukasi article regenerated after the admin reworded the disclaimer:** the article ends with exactly one disclaimer, the new one. → Task 3 test `withDisclaimer after rewording`.
4. **A non-admin calling admin APIs** (save template, save disclaimer, set folder, upload background): 403, and nothing is stored. → Task 2 test `disclaimer non-admin`, Task 4 test `template non-admin`.
5. **A user without Event & Lead access, or an event from another branch:** the event list is empty, and a single-event fetch returns 404. → Task 7 tests `brand-events unknown user`, `brand-events other branch`.

### Task 6: Drive files

**Files:**
- Modify: `apps/brand-kit/worker.js`, `apps/brand-kit/test.mjs`, `apps/brand-kit/i18n.js`

**Interfaces:**
- Produces:
  - `folderId(input)`: accepts a raw id or any Drive folder URL, and returns an id matching `/^[A-Za-z0-9_-]{10,100}$/` or `""`.
  - `POST /api/drive` (admin) `{ folder }`:
    - Stores cfg `drive_folder`.
    - Clears the KV `files` cache.
  - `GET /api/files?fresh=1` (`fresh` is honoured for admins only) → `{ folder, categories: [{ name, files: [{ id, name, mime, size, modified, thumb, view, download }] }], error? }`.
    - **Listing:**
      - Root children via `https://www.googleapis.com/drive/v3/files?q='<id>' in parents and trashed=false&fields=files(id,name,mimeType,size,modifiedTime)&pageSize=1000&orderBy=name&key=<DRIVE_API_KEY>`.
      - Each subfolder (max 30) is listed the same way and becomes a category in name order.
      - Root files go into category `Lainnya` (last).
    - **Links:**
      - `thumb = https://drive.google.com/thumbnail?id=<id>&sz=w400`
      - `view = https://drive.google.com/file/d/<id>/view`
      - `download = https://drive.google.com/uc?export=download&id=<id>`, or `""` for `application/vnd.google-apps.*` files, which only have `view`.
    - **Cache:** KV key `files`, JSON `{ at, data }`, 600 s.
    - **Errors:**
      - Missing key → `{ categories: [], error: "DRIVE_API_KEY belum dipasang." }`.
      - Folder not set → `error: "Folder Drive belum diatur admin."`.
      - Drive HTTP error → `error: "Google Drive tidak bisa dibaca (HTTP <n>)."`, and the last cached data is returned when available.

### Task 8: Render engine (`assets/render.js`)

**Files:**
- Create: `apps/brand-kit/assets/render.js`, `apps/brand-kit/render.test.mjs` (pure parts; run with Node)

**Interfaces:**
- Consumes: the size and slot shapes from Task 4 (`SIZES` is passed in, not imported from the worker).
- Produces (ES module exports):
  - `canvasScale(w, h, max = 16e6)` → `number` ≤ 1.
  - `rowsFor(n)` → array of row lengths: `1→[1]`, `2→[2]`, `3→[3]`, `4→[2,2]`, `5→[3,2]`, `6→[3,3]`.
  - `speakerLayout(slot, n)` → `[{ cx, cy, r, nameY, titleY, w }]`. Rows are centred in the slot box. The diameter is the largest that fits both width and height, after reserving space for the name and title lines.
  - `speakersFor(list, max)` → `{ shown, cut }`, where `cut = list.length - shown.length`.
  - `fitText(measure, text, slot)` → `{ lines, size, overflow }`.
    - `measure(text, size)` returns a width.
    - Wraps on spaces. The line count is limited by `slot.h / (size × 1.2)`.
    - Shrinks by 1 px down to `slot.minSize`.
    - `overflow = true` when it still does not fit. Lines are then cut to fit, with `…` on the last one.
  - `fieldsOf(sizes)` → the union of text fields by `field` key: `[{ field, label, required, max, auto, def }]`, first occurrence wins, plus `speakers: maxOf` and `qr: bool`.
  - `async draw(ctx, { size, bg, values, speakers, qrMatrix, logo, disclaimer, scale })`: draws the background, then logo, text slots, speakers (circle-clipped photo with crop `{ x, y, zoom }`), QR, and disclaimer, in that order.
    - Skips empty optional slots.
    - Returns `{ overflow: [field…], cut }`.
  - `async toPdf(jsPDF, canvas, mm)` → a Blob (one page, `[mm[0], mm[1]]`, image fills the page).
